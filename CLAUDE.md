# Gwiazdki

A family motivation PWA: children check off daily tasks, a parent approves them, and approved tasks earn Stars that convert to a PLN reward per contract period. See `CONTEXT.md` for the domain language.

## Agent skills

### Issue tracker

Issues, including the wayfinder map, live in GitHub Issues on `zzyx/gwiazdka`. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
